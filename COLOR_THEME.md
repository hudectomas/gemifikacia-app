# 🎨 Farebná Téma - Modro-Sivá Paleta

## 📋 Hlavné Farby (ladené s bielo-modro-sivým logom)

### Primárne Farby
```dart
primaryColor: #2196F3    // Sky Blue (hlavná modrá z loga)
secondaryColor: #607D8B  // Blue Grey (sivá z loga)
accentColor: #03A9F4     // Light Blue (svetlá modrá)
```

### Statusové Farby
```dart
successColor: #4CAF50    // Green (zelená pre úspech)
errorColor: #FF5252      // Red (červená pre chyby)
warningColor: #FF9800    // Orange (oranžová pre varovanie)
infoColor: #00BCD4       // Cyan (cyan pre info)
```

### Gradienty
```dart
primaryGradient:
  - #1976D2 → #42A5F5    // Deep Blue → Light Blue

secondaryGradient:
  - #546E7A → #90A4AE    // Blue Grey gradient

goldGradient (na bodíky):
  - #42A5F5 → #64B5F6    // Light Blue gradient
```

## 🎨 Vizuálna Hierarchia

### Primárna Akcia
- Gradient: Deep Blue → Light Blue
- Používa sa pre hlavné akcie (QR scan, hlavné tlačidlá)

### Sekundárna Akcia
- Gradient: Blue Grey
- Používa sa pre menej dôležité akcie

### Akcent/Zvýraznenie
- Gradient: Light Blue / Cyan
- Používa sa pre body, úspechy, zvýraznenia

### Dokončené/Úspech
- Gradient: Cyan
- Používa sa pre dokončené úlohy

## 📱 Prečo Táto Paleta?

✅ **Ladí s logom** - bielo-modro-sivé farby
✅ **Moderný dizajn** - čistý, profesionálny vzhľad
✅ **Dobrý kontrast** - čitateľné texty
✅ **Príjemné pre oči** - nie príliš jasné farby
✅ **Jednotný vzhľad** - všetky screens majú rovnakú tému
